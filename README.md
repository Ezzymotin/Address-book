# Address Book Application

## Project Overview
This is a simple address book application that allows users to add, view, and store contact information such as names, emails, and phone numbers.

## Features
- Adds new contacts
- Display contact list dynamically

## Technologies Used
- HTML for structure
- JavaScript for interactivity
- CSS for web styling

## How to Run the Project
1. Clone the repository or download the project files.
2. Open `index.html` in a browser to see the application.
3. Add contacts using the form, and view the list updated in real-time.

## Future Improvements
- Add functionality to edit and delete contacts.
- Integrate local storage to persist contacts.
